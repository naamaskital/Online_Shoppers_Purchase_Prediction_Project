## Class-Imbalance Analysis

The class-imbalance comparison is stored in:

```text
imbalance_comparison.csv
```

The experiment compares:

* A majority-class Dummy Classifier.
* Models trained without class weighting.
* Models trained with balanced class weights.

The experiment demonstrates why Accuracy alone is not sufficient for this dataset.

A classifier that always predicts the majority class achieves high Accuracy, but its Precision, Recall, and F1 for purchase sessions are zero.

The balanced Random Forest substantially improved Recall and F1 compared with the unbalanced version, although Accuracy and Precision decreased slightly.

These outputs are generated by:


## PCA, SMOTE, and KNN Experiment

The dimensionality-reduction and oversampling comparison is stored in:

```text
pca_knn_comparison.csv
pca_knn_dimension_summary.csv
pca_knn_explained_variance.csv
pca_knn_classification_reports.txt
pca_knn_cumulative_explained_variance.png
pca_knn_metric_comparison.png
```

The experiment compares four configurations:

1. Baseline KNN.
2. PCA followed by KNN.
3. SMOTE followed by KNN.
4. PCA followed by SMOTE and KNN.

### PCA dimension selection

The original dataset contains 17 input features.

After numerical scaling and one-hot encoding, the training data contained 75 processed features.

PCA was configured to retain at least 90% of the cumulative explained variance.

It selected:

```text
20 PCA components
90.845% cumulative explained variance
```

The dimensionality was therefore reduced from 75 processed features to 20 principal components.

### Results

| Model             | Accuracy | Precision | Recall |     F1 | ROC AUC |
| ----------------- | -------: | --------: | -----: | -----: | ------: |
| KNN baseline      |   0.8767 |    0.6822 | 0.3822 | 0.4899 |  0.7633 |
| PCA + KNN         |   0.8694 |    0.6327 | 0.3743 | 0.4704 |  0.7899 |
| SMOTE + KNN       |   0.7506 |    0.3461 | 0.6859 | 0.4601 |  0.7810 |
| PCA + SMOTE + KNN |   0.7806 |    0.3833 | 0.6832 | 0.4911 |  0.7962 |

PCA alone did not improve KNN F1 or Recall.

SMOTE substantially increased Recall, but lowered Accuracy and Precision.

The combined PCA and SMOTE pipeline achieved a better balance than SMOTE without PCA. It improved Accuracy, Precision, F1, and ROC AUC while maintaining almost the same Recall.

The combined pipeline followed this order:

```text
Preprocessing → PCA → SMOTE → KNN
```

All transformations and oversampling were fitted only on the training data. The test set remained untouched until final evaluation.

These outputs are generated by:

```text
scripts/07_pca_knn_experiment.py
```

### Best cross-validation configuration

```text

```

### Test-set comparison

| Model                     | Accuracy | Precision | Recall |     F1 | ROC AUC |
| ------------------------- | -------: | --------: | -----: | -----: | ------: |
| Untuned PCA + SMOTE + KNN |   0.7806 |    0.3833 | 0.6832 | 0.4911 |  0.7962 |

The tuned model improved:

* Accuracy.
* Precision.

However, it reduced:

* Recall.
* F1.
* ROC AUC.

The selected cross-validation configuration therefore did not improve the main test-set metric.

The preferred KNN extension remained:

```text

Selected PCA components: 20
Number of neighbors: 5
Weights: uniform
```

## Main Experimental Conclusions

The result files support the following conclusions:

* Accuracy alone is misleading for the imbalanced target.
* Class weighting improved Random Forest Recall and F1.
* The balanced Random Forest achieved the strongest overall result.
* `PageValues` was the most influential Random Forest feature.
* AdaBoost performed well but did not outperform Random Forest.
* Two PCA components were insufficient to represent most of the dataset variance.
* PCA reduced the processed KNN feature space from 75 features to 20 components while retaining approximately 90.845% of the variance.
* PCA alone did not improve KNN.
* SMOTE substantially increased KNN Recall.
* PCA combined with SMOTE improved the result compared with SMOTE alone.
* The combined KNN pipeline did not outperform the balanced Random Forest.
* Grid Search did not improve the combined KNN test-set F1 score.
* Better cross-validation performance did not guarantee better test-set performance.

## Reproducibility Notes

The numerical values presented in the main README and final report are taken directly from the CSV and JSON files in this directory.

The experiments use fixed random seeds where applicable:

```text
random_state = 42
```

Runtime values can vary between computers and software environments.

Small numerical differences may occur between versions of:

* Python
* pandas
* NumPy
* scikit-learn
* imbalanced-learn

The stored result files preserve the outputs used in the project report.
